📋 Instrucciones para el propietario

🍎 iPhone (iOS Safari)
  1. 1. Abre el link en Safari (no Chrome)
  2. 2. Toca el ícono de Compartir ⬆ abajo
  3. 3. Selecciona "Agregar a pantalla de inicio"
  4. 4. Toca Agregar arriba a la derecha
  5. 5. Abre la app desde tu pantalla de inicio 📱
🤖 Android (Chrome)
  1. 1. Abre el link en Chrome
  2. 2. Aparecerá un banner "Instalar app" — tócalo
  3. 3. O toca el menú ⋮ → "Agregar a pantalla de inicio"
  4. 4. Abre la app instalada y toma las fotos 📸

Al terminar las fotos, el propietario debe presionar "Volver al CRM" — las fotos aparecerán automáticamente aquí.
